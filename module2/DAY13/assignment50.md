# Assignment 50 – Capstone Project Proposal

## 1. Project Title

Student Study Planner – A Task and Study Management Web Application

## 2. Project Overview

Student Study Planner is a web-based application designed to help students organize their daily study activities, assignments and tasks.

The application allows students to add, update, complete and delete tasks. It also helps them track their pending and completed activities.

The main purpose of this project is to make study planning easier and improve time management.

## 3. Problem Statement

Students often find it difficult to manage their assignments, daily study schedules and deadlines.

They may forget important tasks or struggle to track their completed work.

This application provides a simple platform to organize and manage these activities.

## 4. Project Objectives

* Make daily study planning easier.
* Help students manage assignments and tasks.
* Track pending and completed tasks.
* Save task information in browser storage.
* Provide a simple and user-friendly interface.

## 5. Core Features

1. **Dashboard:** Display an overview of study activities.
2. **Add Task:** Add new study tasks and assignments.
3. **Edit Task:** Update existing task information.
4. **Delete Task:** Remove unnecessary tasks.
5. **Mark as Complete:** Track completed activities.
6. **Task Filtering:** View all, pending and completed tasks.
7. **Persistent Storage:** Save tasks using localStorage.
8. **Responsive Design:** Support desktop and mobile screens.

## 6. User Requirements

### Functional Requirements

* Users should be able to add new tasks.
* Users should be able to edit and delete tasks.
* Users should be able to mark tasks as completed.
* Users should be able to filter tasks.
* The application should save data in localStorage.
* Previously saved tasks should appear after refreshing the page.

### Non-Functional Requirements

* The interface should be simple and user-friendly.
* The application should load quickly.
* The layout should be responsive.
* The code should be easy to understand and maintain.
* User data should remain available in the same browser.

## 7. Technologies Used

* HTML5 – Structure of the application.
* CSS3 – Styling and responsive layout.
* JavaScript – Application functionality.
* DOM Manipulation – Dynamic webpage updates.
* localStorage – Persistent data storage.
* VS Code – Development environment.
* Git and GitHub – Version control and project submission.

## 8. Target Users

The application is designed for:

* College students.
* School students.
* Students managing multiple assignments.
* Anyone who wants to organize daily study activities.

## 9. Expected Outcome

The final application will provide an easy way to manage study tasks and assignments.

Students will be able to organize their activities, track their progress and access saved tasks even after refreshing the webpage.

## 10. Conclusion

Student Study Planner is a practical web development project that uses HTML, CSS and JavaScript concepts.

It combines DOM manipulation, event handling and browser storage to create a useful application for students.
