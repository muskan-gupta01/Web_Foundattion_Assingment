# Assignment 61: Student Study Planner User Guide

## 1. Project Introduction

The Student Study Planner is a web-based application that helps students organize and manage their study tasks. It allows users to add, edit, complete, filter and delete tasks.

## 2. Technologies Used

* HTML – Creates the structure of the application.
* CSS – Provides styling and responsive layout.
* JavaScript – Handles application functionality.
* LocalStorage – Saves tasks in the browser.

## 3. How to Use the Application

### Step 1: Open the Application

Open the `index.html` file in a web browser using VS Code Live Server.

### Step 2: Add a Task

Enter the task title, subject and due date in the form. Click the Add Task button to create a task.

### Step 3: Edit a Task

Click the Edit button on a task to update its details.

### Step 4: Complete a Task

Click the Complete button when a task is finished. You can also undo this action if required.

### Step 5: Delete a Task

Click the Delete button to remove a task from the list.

### Step 6: Filter Tasks

Use the All, Pending and Completed filters to view tasks according to their status.

## 4. Data Storage

The application uses LocalStorage to save task information in the browser. Tasks remain available after refreshing or reopening the page in the same browser.

## 5. Dashboard

The dashboard displays:

* Total Tasks
* Pending Tasks
* Completed Tasks

These values update when tasks are added, edited, completed or deleted.

## 6. Conclusion

The Student Study Planner provides a simple way to manage study activities. It helps students organize their tasks, track progress and maintain a better study schedule.
